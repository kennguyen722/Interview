# Module Project - Module 4: Spring Boot Backend Development (Weeks 11-14)

This module now contains a production-grade Spring Boot baseline for lessons 4.1 through 4.5.

## Start Here

- Solution project: [solution/README.md](./solution/README.md)
- Evaluation rubric: [RUBRIC.md](./RUBRIC.md)

## What Is Implemented

- Layered Spring Boot architecture (controller, service, repository)
- Input validation and global exception handling
- Versioned REST API with pagination
- Spring Data JPA entities and relationships
- Flyway schema + seed migrations
- Query performance baseline using `@EntityGraph` and indexed columns
- Dockerized PostgreSQL and local test profile with H2
- Web and repository tests

## Intended Learning Flow

1. Lesson 4.1: inspect bean wiring and profiles.
2. Lesson 4.2: extend API contract and validation behavior.
3. Lesson 4.3: evolve entity model and transactional logic.
4. Lesson 4.4: add forward-only migration and verify startup.
5. Lesson 4.5: optimize query behavior and observe metrics.
