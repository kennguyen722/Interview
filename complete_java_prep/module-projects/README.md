## Unified Smoke Validation

From `complete_java_prep`, run:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run_module_smoke.ps1
```

Optional fail-fast mode:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run_module_smoke.ps1 -FailFast
```
