# Module Project - Module 6: Security and Identity (Weeks 17-18)

This module now contains a production-grade security baseline for lessons 6.1 through 6.4.

## Start Here

- Solution project: [solution/README.md](./solution/README.md)
- Evaluation rubric: [RUBRIC.md](./RUBRIC.md)

## What Is Implemented

- Spring Security stateless authentication pipeline
- JWT access token issuance and validation
- Refresh token lifecycle and rotation
- Role-based authorization (`ROLE_USER`, `ROLE_ADMIN`)
- Secure password hashing and identity schema via Flyway
- Structured API error handling for security workflows

## Intended Learning Flow

1. Lesson 6.1: inspect filter chain and authorization rules.
2. Lesson 6.2: walk through login and refresh token lifecycle.
3. Lesson 6.3: tighten endpoint rules and audit error handling.
4. Lesson 6.4: document secure coding standards and compliance checks.
