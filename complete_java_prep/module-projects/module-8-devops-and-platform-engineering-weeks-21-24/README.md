## What Is Implemented

- Multi-stage Docker builds for backend/frontend
- CI workflow with tests, lint, and security scanning
- Kubernetes manifests with base and overlay strategy
- Prometheus + Grafana starter observability stack
- k6 performance script with actionable thresholds

## Intended Learning Flow

1. Lesson 8.1: run Docker stack and validate image behavior.
2. Lesson 8.2: inspect CI quality gates and security scan stage.
3. Lesson 8.3: deploy with Kustomize overlay on local k8s.
4. Lesson 8.4: open Grafana dashboard and validate metrics.
5. Lesson 8.5: execute k6 and analyze threshold results.
