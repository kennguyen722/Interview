# JavaScript Interview Prep

A complete JavaScript learning and interview-preparation program from novice to expert, focused on real-world enterprise engineering.

## Program Goals

- Build strong core JavaScript fundamentals.
- Progress into async, concurrency, architecture, and systems thinking.
- Practice with practical enterprise problems, not only toy exercises.
- Prepare for Senior and Principal interview rounds.

## Learning Path

1. Novice Fundamentals
2. Intermediate Core Language
3. Advanced Async and Concurrency
4. Advanced Data and Algorithms
5. Enterprise Backend Node.js
6. Patterns and Architecture
7. Quality, Security, and Performance
8. Expert System Design and Leadership

## What You Get

- Full module-by-module curriculum with outcomes and assessments.
- 120+ enterprise-style coding and design problems.
- Interview problem ladders by level and round type.
- Capstone project tracks with acceptance criteria.
- Starter, solution, and runnable tests in every module.

## Advanced Topic Coverage

- generators and iterators
- symbols
- weak maps and weak sets
- property descriptors
- optional chaining and nullish coalescing
- module systems: CommonJS vs ESM
- Node streams basics
- backpressure concept
- abort signals and cancellation

See: [tracks/advanced-topics-checklist.md](tracks/advanced-topics-checklist.md)
