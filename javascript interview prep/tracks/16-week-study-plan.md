# 16-Week JavaScript Interview Study Plan (Novice to Expert)

## Weekly Rhythm

- Day 1-4: Learning plus coding drills
- Day 5: Enterprise problem implementation
- Day 6: Mock interview round
- Day 7: Retrospective and weak-area repair

## Plan

### Weeks 1-2
- Module 01 focus
- Target: 25 solved fundamentals problems

### Weeks 3-4
- Module 02 focus
- Target: 20 intermediate language and design utility problems

### Weeks 5-6
- Module 03 focus
- Target: 20 async/concurrency/reliability coding problems

### Weeks 7-8
- Module 04 focus
- Target: 20 algorithm problems with complexity explanations

### Weeks 9-10
- Module 05 focus
- Target: implement idempotency, pagination, validation, auth middleware

### Weeks 11-12
- Module 06 focus
- Target: architecture patterns and workflow reliability drills

### Weeks 13-14
- Module 07 focus
- Target: security hardening, deterministic tests, p95/p99 optimization

### Weeks 15-16
- Module 08 focus
- Target: complete capstone and principal-level mock rounds

## Milestones

1. Week 4 milestone:
- Ship a utility package with tests and docs.

2. Week 8 milestone:
- Pass timed coding mock with strong communication.

3. Week 12 milestone:
- Build resilient API service with observability hooks.

4. Week 16 milestone:
- Deliver capstone design, implementation, and leadership defense.
