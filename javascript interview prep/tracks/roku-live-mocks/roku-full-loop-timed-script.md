# Roku Full Loop Timed Script (One Sitting)

Use this to simulate one realistic Senior Advertising interview loop.

Total time: 180 minutes

## Session Plan

1. Coding round: 60 minutes
- Use one candidate prompt from this folder.

2. System design round: 60 minutes
- Use prompt: Design near-real-time reporting for impressions, clicks, conversions, spend, and ROAS.

3. Behavioral round: 45 minutes
- Answer 5 leadership questions using STAR.

4. Debrief: 15 minutes
- Capture strengths, misses, and next actions.

## Coding Round Script (60 minutes)

- Minute 0 to 5:
  - Restate problem and assumptions.
  - Confirm API and edge conditions.

- Minute 5 to 10:
  - Pick data structures and complexity target.
  - Sketch function boundaries.

- Minute 10 checkpoint:
  - You must have a clear plan and signatures.

- Minute 10 to 30:
  - Implement core happy path.

- Minute 30 checkpoint:
  - Happy path should run with one manual sample.

- Minute 30 to 50:
  - Add edge cases and failure handling.
  - Add at least 4 focused tests.

- Minute 50 checkpoint:
  - Must handle duplicates, boundary windows, and invalid input.

- Minute 50 to 60:
  - Explain tradeoffs, scale limits, and production hardening.

## System Design Script (60 minutes)

- Minute 0 to 8:
  - Clarify scope, non-goals, KPIs, and latency targets.

- Minute 8 to 20:
  - Propose high-level architecture and main data flows.

- Minute 20 to 35:
  - Drill into data model, ingestion path, and query path.

- Minute 35 to 45:
  - Reliability plan: retries, dedupe, replay, alerts, SLOs.

- Minute 45 to 55:
  - Tradeoffs and alternatives.

- Minute 55 to 60:
  - Summarize with phased rollout plan.

## Behavioral Script (45 minutes)

Prepare answers for:

1. Tell me about a high-severity incident you led.
2. Tell me about a difficult cross-team architecture disagreement.
3. Tell me about a decision where you traded speed for quality.
4. Tell me about mentoring an engineer to raise team quality.
5. Tell me about a failed project and what you changed.

For each answer include:

- context and business impact
- your specific actions
- measurable outcome
- what you would improve next time

## Self-Score Rubric

Score 1 to 5 on each:

- problem clarification
- implementation correctness
- test depth
- complexity and tradeoffs
- reliability mindset
- communication clarity

Target average: 4 or above.
