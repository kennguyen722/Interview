# Advanced Topics Checklist (Interview Level)

This checklist is now integrated into Module 02 and Module 03 practice packs.

## Language and Runtime Depth

- Generators and iterators
- Symbols
- WeakMap and WeakSet
- Property descriptors
- Optional chaining and nullish coalescing
- Module systems: CommonJS vs ESM

## Node and Concurrency Depth

- Node streams basics
- Backpressure concept
- Abort signals and cancellation

## Expected Interview Outcomes

- Explain where each feature solves real production pain.
- Implement small utilities without external libraries.
- Discuss tradeoffs, not just syntax.
