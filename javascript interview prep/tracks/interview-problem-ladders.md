# Interview Problem Ladders by Level

## Novice Ladder

- Goal: write correct JavaScript with clean control flow.
- Typical rounds: entry-level coding and pair programming.

Practice sequence:
1. Functions and object manipulation
2. Array transforms and map/set usage
3. Input validation and defensive coding
4. Small async tasks (basic promises)

## Intermediate Ladder

- Goal: explain language mechanics and write maintainable modules.
- Typical rounds: coding + practical service logic.

Practice sequence:
1. this/prototype/module behavior
2. Data transformation with complexity awareness
3. Error handling and custom error classes
4. Basic API flow implementation

## Advanced Senior Ladder

- Goal: solve practical production tasks under constraints.
- Typical rounds: coding, debugging, API design.

Practice sequence:
1. Concurrency controls and retries
2. Pagination, idempotency, rate limiting
3. N+1 elimination and transaction safety
4. Testing strategy and failure mode handling

## Expert Principal Ladder

- Goal: combine implementation, architecture, and leadership judgment.
- Typical rounds: system design, incident leadership, architecture review.

Practice sequence:
1. Reliability patterns and SLO design
2. Multi-service workflow and consistency strategy
3. Security posture and governance policy
4. ADR writing and tradeoff communication

## Round-Specific Drill Packs

### Coding Round
- 45 to 60 minutes
- Requirements: correctness, edge cases, complexity, readable code

### Practical Engineering Round
- 60 minutes
- Requirements: production-safe design, validation, observability, tests

### Debugging Round
- 30 to 45 minutes
- Requirements: root-cause analysis, low-risk fix, verification plan

### System Design Round
- 45 to 60 minutes
- Requirements: assumptions, capacity, bottlenecks, reliability, migration

### Leadership Round
- 30 to 45 minutes
- Requirements: influence, standards, decision quality, measurable outcomes
