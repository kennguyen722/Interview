# Capstone Projects: Novice to Expert

## Capstone 1 (Novice): Business Rules Engine

Build a small rules engine for order discount calculations.

Requirements:
- Parse rules from config.
- Validate rule schemas.
- Produce deterministic output for same input.
- Include test suite and failure cases.

## Capstone 2 (Intermediate): Event-Driven Task Board

Build a local task board backend in pure JavaScript.

Requirements:
- Event bus for task lifecycle events.
- In-memory persistence with snapshots.
- Input validation and error taxonomy.
- Logging with correlation IDs.

## Capstone 3 (Advanced): Resilient API Service

Build a Node.js service for order and payment simulation.

Requirements:
- Idempotent create endpoint.
- Cursor pagination and filtering.
- Timeout, retry, circuit breaker, and bulkhead on downstream calls.
- Structured logs and metrics hooks.

## Capstone 4 (Expert): Enterprise Workflow Platform Slice

Build a minimal distributed workflow simulator.

Requirements:
- Saga orchestration and compensation.
- Outbox and event replay safety.
- Multi-tenant isolation controls.
- SLO dashboard calculations and incident runbook.

## Evaluation Rubric

- Correctness and edge-case coverage
- Reliability and fault tolerance
- Security and defensive controls
- Code quality and modular architecture
- Test depth and observability
- Communication and tradeoff clarity
