# Module 04: Advanced Data and Algorithms

## Objective
Solve interview and production algorithm problems with performance and maintainability in mind.

## Topics
- Hash maps, sets, queues, stacks
- Linked lists, trees, graphs
- Sliding window, two pointers, heap
- Topological sort and cycle detection
- Complexity analysis under constraints

## Hands-on Labs
1. Build LRU cache from scratch.
2. Log anomaly detector using sliding windows.
3. Dependency scheduler with topo sort.
4. Search index with prefix matching.
5. Streaming percentile estimator.
