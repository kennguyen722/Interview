# Module 02: Intermediate Core Language

## Objective
Develop deeper JavaScript language mastery required for maintainable production code.

## Topics
- this, call/apply/bind
- Prototype chain and object model
- Classes and composition
- Modules and dependency organization
- Immutability and pure function design
- Data transformation patterns

## Advanced Topics (Interview Level)
- generators and iterators
- symbols
- weak maps and weak sets
- property descriptors
- optional chaining and nullish coalescing
- module systems: CommonJS vs ESM
