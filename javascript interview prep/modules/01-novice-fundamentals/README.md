# Module 01: Novice Fundamentals

## Objective
Build strong basics in pure JavaScript syntax, logic, and debugging.

## Topics
- Variables, primitive/reference types, operators
- Conditional logic and loops
- Functions, parameters, return values
- Arrays, objects, and common operations
- Scope basics and introductory closures
- Error handling with try/catch

## Hands-on Labs
1. Invoice total calculator with discount rules.
2. Form input validator for signup data.
3. Product catalog filter and sort utility.
4. Role-based menu visibility generator.
5. Command-line gradebook analyzer.
