# Module 06: Patterns and Architecture

## Objective
Apply software design patterns and architecture principles to scalable JavaScript systems.

## Topics
- SOLID and clean architecture in JS
- Factory, strategy, observer, command, adapter
- Repository and service layers
- BFF and API gateway patterns
- Event-driven architecture, saga, outbox
- Monolith to modular migration strategy

## Hands-on Labs

2. Implement saga orchestration simulator.
3. Add outbox processor and replay handler.
4. Create pluggable policy engine.
