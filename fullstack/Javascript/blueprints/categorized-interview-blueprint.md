# Categorized Interview Blueprint

## Target roles
- Senior Full Stack Software Engineer
- Principal Full Stack Software Engineer

## Interview loop architecture

| Round | Duration | Focus | Senior bar | Principal bar |
|---|---:|---|---|---|
| Coding 1 | 60m | DSA + JS fundamentals | Correct + clean + O() | Tradeoff-rich + edge-safe |
| Coding 2 | 45m | Practical FE/BE coding | Production-minded implementation | Cross-layer reliability thinking |
| Debugging | 30m | Root cause under pressure | Systematic diagnosis | Incident leadership framing |
| API/Architecture | 45m | Service and contracts | Clear boundaries and validation | Evolution/migration governance |
| System Design | 60m | Scale/reliability | Coherent design with assumptions | Capacity, failure, and org tradeoffs |
| Leadership | 30m | Behavioral/judgment | Ownership stories | Org-level influence and standards |

## Scoring dimensions
- Correctness
- Complexity and tradeoff analysis
- Code quality and maintainability
- Reliability and resilience
- Security posture
- Communication and collaboration
- Leadership/multiplier impact

## Question category matrix
- JavaScript internals: scope, closures, prototypes, event loop.
- Algorithms: array/map/string/tree/graph/DP/window/heap.
- Frontend practical: rendering, state, hydration, performance.
- Backend practical: API design, idempotency, pagination, rate limits.
- Full stack integration: BFF, optimistic UI, consistency, contracts.
- Data layer: transactions, migration, indexing, N+1 elimination.
- Reliability/security: timeout/retry/circuit/bulkhead, OWASP, authn/authz.
- Principal domains: ADRs, technical influence, incident leadership.
