# Mock Interview Sections (Senior and Principal)

## Format A: Senior Full Stack Loop (2.5 hours)

### Round 1: Coding (60 min)
- 1 algorithmic question (35 min)
- 1 practical JavaScript question (25 min)

Scoring focus:
- correctness
- complexity
- communication clarity
- code hygiene

### Round 2: Practical Engineering (45 min)
- implement an API handler with validation, idempotency, and error taxonomy
- include tests for edge cases

Scoring focus:
- production safety
- observability awareness
- defensive coding

### Round 3: Debugging (30 min)
- investigate flaky behavior and identify root cause
- propose low-risk rollout fix

Scoring focus:
- hypothesis discipline
- speed to root cause
- rollback awareness

### Round 4: Behavioral (15 min)
- ownership story
- conflict resolution story
- quality/security decision story

Scoring focus:
- impact scope
- decision quality
- learning loop

## Format B: Principal Full Stack Loop (3.5 hours)

### Round 1: Advanced Coding and Reliability (60 min)
- concurrency control + resilience policy extension

### Round 2: Architecture Review (60 min)
- critique design and identify long-term risk
- provide migration strategy and ADR outline

### Round 3: System Design Crossover (60 min)
- design end-to-end full-stack system
- capacity and failure modeling required

### Round 4: Leadership and Technical Judgment (30 min)
- influence without authority
- org-wide standards, tradeoffs, and execution plan

### Round 5: Code Review (20 min)
- identify correctness/security/performance issues in prewritten code

## Interviewer scorecard dimensions

| Dimension | 1-2 | 3-4 | 5 |
|---|---|---|---|
| Correctness | Frequent misses | Mostly correct | Correct + anticipates hidden failures |
| Tradeoff analysis | Superficial | Adequate | Quantified and context-aware |
| Reliability/security | Reactive | Covers basics | Proactive and systemic |
| Communication | Unstructured | Understandable | Drives clarity and alignment |
| Leadership signal | Local impact only | Team impact | Org-level multiplier behavior |

## Pass thresholds
- Senior target: average >= 3.8 and no red flags in reliability/security.
- Principal target: average >= 4.3 and at least one clear org-level leadership signal.
