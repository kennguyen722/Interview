# 12-Week Study Plan (Senior/Principal Full Stack JavaScript)

## Weekly cadence
- Monday-Thursday: focused implementation drills.
- Friday: timed mock interview.
- Saturday: post-mortem and targeted rework.
- Sunday: light review and behavioral prep.

| Week | Focus | Daily target | Weekly deliverable |
|---|---|---|---|
| 1 | JS runtime fundamentals | 2 core JS drills/day | 60-min JS internals mock |
| 2 | Async/event loop/concurrency | 2 async drills/day | Concurrency pool implementation |
| 3 | DSA patterns I | 3 DSA drills/day | 90-min coding mock |
| 4 | DSA patterns II | 3 DSA drills/day | Weak-area retest |
| 5 | Frontend engineering | 1 FE practical + 1 DSA/day | UI performance mini-project |
| 6 | Node/API engineering | 1 BE practical + 1 DSA/day | Idempotent endpoint + tests |
| 7 | Full stack integration | 2 integration drills/day | BFF + optimistic UI scenario |
| 8 | Data layer/consistency | 2 persistence drills/day | N+1 fix + migration exercise |
| 9 | Testing/debugging | 2 debugging tasks/day | Incident-style debug simulation |
| 10 | Performance/reliability | 2 resilience drills/day | Retry/bulkhead/circuit toolkit |
| 11 | Security/system design | 1 security + 1 design/day | Threat model + 45-min design mock |
| 12 | Principal loop simulation | full-loop practice | Final panel (coding/design/leadership) |

## Completion criteria
- All section drills completed with written post-mortems.
- At least 3 full mock loops completed in Weeks 10-12.
- Consistent pass on code quality, reliability, and communication rubric.
