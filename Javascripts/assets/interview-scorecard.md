# Interview Scorecard (Self-Assessment)

Score each dimension from 1 to 10 after every mock interview.

## Coding Quality

- Problem understanding and assumptions
- Correctness and edge cases
- Code readability and maintainability
- Tests and validation quality

## Computer Science Fundamentals

- Time complexity analysis
- Space complexity analysis
- Data structure choice rationale
- Trade-off discussion clarity

## Production-Grade Engineering

- Error handling and resilience
- Observability (logs, metrics, traces)
- Security and input validation
- API contract and backward compatibility

## Architecture and Scale

- Service boundary design
- Scalability strategy
- Consistency model and failure handling
- Performance tuning approach

## Communication

- Clarity of thought process
- Structured explanation
- Ability to receive hints and adapt
- Confidence without overclaiming

## Promotion Rubric

Move to advanced-only interview prep when:
- 3 consecutive coding mocks average >= 8
- 3 consecutive design mocks average >= 8
- Reliability and performance sections average >= 7.5
