# 16-Week JavaScript Interview Study Plan

## Weekly Cadence

- 5 days coding practice
- 1 day system design + architecture discussion
- 1 day review + mock interview

## Weeks 1-4: Foundations

Week 1:
- Scope, closures, objects, arrays
- 6 coding drills (easy -> medium)
- Deliverable: utility module with tests

Week 2:
- Functions, composition, clean code patterns
- 6 coding drills + 1 refactoring task
- Deliverable: functional utilities library

Week 3:
- Data structures and complexity reasoning
- 8 interview-style algorithm problems
- Deliverable: LRU cache + complexity notes

Week 4:
- Event loop, promises, async control
- 6 async problems + race condition debugging
- Deliverable: `retryWithBackoff`, `promisePool`, timeout wrapper

## Weeks 5-8: Professional Coding

Week 5:
- DOM event handling and event delegation
- Build: event-driven UI widget system

Week 6:
- Node.js API design, validation, error handling
- Build: production-grade CRUD API with logging

Week 7:
- Testing strategy and quality gates
- Build: unit + integration test suite with coverage target

Week 8:
- Security and defensive programming
- Build: API hardening patch set + threat checklist

## Weeks 9-13: Architecture and Scale

Week 9:
- Architecture styles and modular boundaries
- Exercise: refactor monolith module boundaries

Week 10:
- Scalability patterns and caching strategy
- Exercise: design high-traffic endpoint architecture

Week 11:
- Microservices and event-driven workflows
- Exercise: model event contracts and failure handling

Week 12:
- Reliability patterns and incident response design
- Exercise: timeout/retry/circuit breaker in service integration

Week 13:
- Performance profiling and optimization
- Exercise: optimize p95 latency in benchmarked endpoint

## Weeks 14-16: Interview Simulations and Capstones

Week 14:
- Mock coding interviews (3 sessions)
- Focus: explanation quality and edge-case handling

Week 15:
- Mock system design interviews (3 sessions)
- Focus: scale, resilience, observability, deployment

Week 16:
- End-to-end capstone implementation and demo
- Focus: production-grade choices and trade-off articulation

## Score Goals by Week 16

- Coding round: 8/10 or above
- System design round: 8/10 or above
- Debugging round: 8/10 or above
- Communication and trade-offs: 8/10 or above
