## Principal-Level Interview Domains

### What Interviewers Test at This Level

1. **System Ownership** — Can you own an entire domain end-to-end? DB schema → API → frontend → monitoring?
2. **Cross-cutting Concerns** — Auth, logging, rate limiting, error propagation across layers.
3. **Trade-off Articulation** — Why REST vs GraphQL? Why JWT vs sessions? Why SQL vs NoSQL?
4. **Code Review** — Can you find subtle bugs, performance issues, and security flaws in existing code?
5. **Technical Leadership** — Can you write ADRs, set standards, and guide a team on architectural decisions?
6. **Reliability Ownership** — Can you define SLOs, set up alerting, and own incident response?
