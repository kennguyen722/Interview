## Timebox
- Coding round: 45 minutes

## Coding Round (0-10)
- Idempotency implementation correctness (0-3)
- Input validation and API contract quality (0-2)
- Error handling and reliability controls (0-2)
- Maintainability and testability (0-2)
- Communication clarity (0-1)

## Debugging Round (0-10)
- Retry storm root cause analysis (0-3)
- Bounded retry/backoff fix quality (0-3)
- Operational risk mitigation (0-2)
- Explanation quality (0-2)

## Design Round (0-10)
- Failure-mode coverage (0-3)
- Circuit breaker/retry/timeout strategy (0-3)
- Observability and SLO planning (0-2)
- Consistency and reconciliation plan (0-2)

## Pass Guidelines
- Minimum 7 in each round
- Overall average >= 8
