## Timebox
- Coding round: 45 minutes
- Debugging round: 30 minutes
- Design round: 45 minutes

## Coding Round (0-10)
- Correctness of debounce/cancellation/stale-response handling (0-3)
- Code structure and readability (0-2)
- Edge cases and failure handling (0-2)
- Complexity explanation and trade-offs (0-2)
- Communication clarity (0-1)

## Debugging Round (0-10)
- Root cause identification speed (0-3)
- Accuracy of fix (0-3)
- Regression prevention strategy (0-2)
- Explanation quality (0-2)

## Design Round (0-10)
- Event architecture quality (0-3)
- Performance strategy (0-2)
- Reliability and fallback plan (0-2)
- Observability/test strategy (0-2)
- Trade-off discussion (0-1)

## Pass Guidelines
- Minimum 7 in each round
- Overall average >= 8
