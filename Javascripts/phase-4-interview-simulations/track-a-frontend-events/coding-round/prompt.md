# Track A Coding Round: Event-Heavy Search UI

## Scenario
You are implementing a typeahead search box for a dashboard used by customer support teams.

## Requirements
- Debounce user input by 250ms.
- Cancel stale requests when a new query starts.
- Ignore out-of-order responses.
- Keep the latest successful result only.

## Task
Complete starter implementation in starter/index.js.

## Timebox
45 minutes
